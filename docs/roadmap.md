# 路线图

本页记录功能方向，不承诺交付日期。优先级可通过 Issue 讨论。

## 已具备

- 七服务启动骨架和共享基础模块。
- 本地演示认证、商品查询、订单试算、会员 ID 查询。
- 本地/中间件/K8S 配置、测试和发布检查。
- 镜像发布流程、独立迁移入口和运维说明。

## 后续方向

1. 身份认证、密码哈希、令牌刷新/撤销、RBAC 和后台管理权限。
2. 商品 SPU/SKU、类目、上下架、图片存储和库存流水。
3. 购物车、幂等下单、价格快照、库存预占和超时关单。
4. 支付回调验签、退款、对账及异常补偿。
5. RocketMQ 消息幂等/重试/死信、事务一致性和可观测性。
6. 商城前端、运营后台及完整业务验收。

这些内容尚未实现，不能依据服务目录的存在推断功能已经完成。
